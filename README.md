✦ Tentang

ReyCode × Monikᵃ Labs adalah ruang untuk membangun, mengembangkan, dan mengeksplorasi berbagai proyek teknologi.

Kami berfokus pada pengembangan:

- 🌐 Website & Web Application
- ⚡ REST API & Backend System
- 🤖 Automation & Bot
- 📱 Mobile Application
- 💬 Real-time Communication
- ☁️ Cloud & Deployment
- 🧠 AI-powered Tools
- 🛠️ Developer Tools
- 🔐 Authentication & Security
- 🚀 Experimental Technology

Setiap proyek dibuat dengan tujuan untuk terus belajar, bereksperimen, dan menghasilkan sesuatu yang bermanfaat.

---

✦ Filosofi

«“Sak dhuwuré ilmu, tetep andhap asor.”»

Dalam bahasa Indonesia:

«“Setinggi apa pun ilmu yang dimiliki, tetaplah rendah hati.”»

Bagi kami, teknologi bukan hanya tentang seberapa tinggi kemampuan seseorang dalam membuat sesuatu.

Teknologi juga tentang bagaimana ilmu tersebut digunakan untuk menciptakan sesuatu yang bermanfaat, terus belajar dari kesalahan, menghargai orang lain, dan tetap rendah hati ketika kemampuan berkembang.

---

✦ Visi

Memajukan Teknologi · Membentuk Masa Depan

Kami percaya bahwa perkembangan teknologi dimulai dari rasa ingin tahu.

Dari satu ide kecil, sebuah eksperimen sederhana, atau bahkan sebuah baris kode, sesuatu yang lebih besar dapat dibangun.

ReyCode × Monikᵃ Labs hadir sebagai tempat untuk:

Belajar → Membangun → Bereksperimen → Berkembang

- Membangun teknologi yang bermanfaat.

✦ Development Principles

01 — Build

Jangan hanya memiliki ide.

Bangun ide tersebut.

02 — Learn

Setiap error adalah bagian dari proses belajar.

03 — Create

Gunakan kemampuan untuk menciptakan sesuatu yang memiliki nilai.

04 — Improve

Project pertama tidak harus sempurna.

Yang penting adalah terus berkembang.

05 — Stay Humble

«Sak dhuwuré ilmu, tetep andhap asor.»

Sebanyak apa pun ilmu yang dimiliki, tetaplah rendah hati.
